   （两边浅切点不同）→ `git fetch origin --unshallow` 补全历史后正常。
2. **build 顺序坑**：server 编译依赖 `@getpaseo/plugin` 的构建产物（usage API 类型）。
   漏建 plugin → 20 个 TS 错误（registerUsageSource/`@getpaseo/plugin/server/usage`）。
   **正确顺序：protocol → client → plugin → server → cli**（不碰 app/desktop/website）。
3. **lefthook pre-commit 陷阱**：跑全仓 typecheck（~57s），且管道 `git commit | tail`
